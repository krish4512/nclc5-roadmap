# Prêt Français brand

- **Mark** (`mark.svg`): a speech bubble — speaking French — carrying the circumflex of
  *prêt* ("ready"), which also reads as an upward step. Use it at 16 px and up.
- **On colour or dark photos** use `mark-white.svg` (white bubble, gradient circumflex).
- **Logo** (`logo.svg`, `logo-white.svg`): mark + wordmark. *Prêt* in Inter Tight 800,
  *Français* in Inter Tight 500, secondary ink.
- **Gradient**: #2451d6 → #6c47e4 → #c2419a (135°). Ink #1d1d1f, secondary #515154.
- Keep clear space of half the mark's height around it. Don't rotate, outline or recolour
  the circumflex separately from the bubble.
